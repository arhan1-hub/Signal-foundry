# SignalFoundry

SignalFoundry is a lightweight MVP for exploring software-product opportunities using evidence from user feedback.

## MVP modules
- Opportunity Radar (demo hypotheses; scores are heuristic, not market facts)
- Review Analyzer (local keyword clustering for pasted feedback)
- Build Brief generator
- Saved reports stored in the browser

## Current limitations
This prototype does not include live app-store feeds, automated web crawling, cloud accounts, or a hosted AI backend. Demo data and heuristic scores must be validated with real users before making business decisions.

## Run locally
Open `index.html` in a modern browser. No build step is required.
